# Code Assistant — Android-чат-помощник по коду

Нативное приложение на Kotlin + Jetpack Compose. Отправляет вопросы в Claude API и показывает ответ потоком (по мере генерации). Блоки кода выводятся в отдельных карточках с кнопкой «Копировать».

## Запуск

1. Откройте папку проекта в **Android Studio** (Ladybug 2024.2 или новее). Студия сама скачает Gradle wrapper и зависимости.
2. Подключите телефон (отладка по USB) или запустите эмулятор, нажмите **Run ▶**.
3. В приложении откройте ⚙, вставьте свой Anthropic API-ключ (создаётся в Claude Console) и сохраните.

Минимальная версия Android — 8.0 (API 26).

## Структура

```
app/src/main/java/com/example/codeassistant/
├── MainActivity.kt        — точка входа, тема
├── ChatScreen.kt          — UI: список сообщений, ввод, настройки, блоки кода
├── ChatViewModel.kt       — состояние чата, запуск/остановка запроса
└── data/
    ├── ClaudeClient.kt    — стриминговый клиент Messages API (OkHttp + SSE)
    └── Prefs.kt           — локальное хранение ключа и названия модели
```

## Что настраивается

- **Модель** — в окне настроек (по умолчанию `claude-sonnet-5-5`).
- **Системный промпт** — константа `SYSTEM_PROMPT` в `ClaudeClient.kt`.
- **Лимит ответа** — `maxTokens = 4096` в `ClaudeClient.kt`.

## Важно про безопасность ключа

Сейчас пользователь вводит ключ сам, он хранится в приватном хранилище приложения. Для личного использования это нормально. Если вы будете публиковать приложение, **не вшивайте ключ в APK** — его легко достать. Вместо этого поднимите небольшой backend-прокси, который хранит ключ и проверяет пользователей, а приложение пусть ходит к нему.

## Идеи для развития

- Подсветка синтаксиса (например, библиотека Sora Editor или разбор через Highlights).
- Рендеринг Markdown (списки, заголовки) в обычном тексте.
- История чатов в Room.
- Интеграция с GitHub API: открыть файл из репозитория и отправить его как контекст, закоммитить предложенную правку.
- Прикрепление файлов из хранилища телефона.

## Версии зависимостей

Версии в `build.gradle.kts` актуальны на момент создания проекта. Если Android Studio предложит обновить Android Gradle Plugin или Compose BOM — можно соглашаться.
